## Funcionalidades

- Tela de recordes gerais na página inicial.
- Conquistas salvas no navegador.
- Botão para zerar recordes e conquistas.
- Seletor de dificuldade nos jogos.
- Sons com opção de mudo.
- Modo claro/escuro.
- PWA com manifest, service worker e suporte offline.
- Favicon e ícones para instalação pelo GitHub Pages.
